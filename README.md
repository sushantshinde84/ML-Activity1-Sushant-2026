## Objective

To inspect a dataset, identify missing values and data-quality issues, perform exploratory data analysis, and prepare a dataset for machine learning.

## Dataset Information

- Dataset Name: Students Performance in Exams
- Domain: Education
- Total Records: 1000
- Total Columns: 8
- File Format: CSV

## Dataset Source

[Kaggle – Students Performance Dataset](https://www.kaggle.com/datasets/spscientist/students-performance-in-exams)

## Work Completed

1. Dataset loading and inspection.
2. Numerical and categorical feature identification.
3. Missing-value analysis and handling.
4. Duplicate removal and data cleaning.
5. Exploratory Data Analysis (EDA).
6. Data visualization using Matplotlib and Seaborn.
7. One-Hot Encoding.
8. Feature scaling using StandardScaler.
9. Saving the prepared dataset as CSV.
